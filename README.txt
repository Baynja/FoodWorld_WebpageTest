FOODWORLD — FINAL HTML & CSS UNIVERSITY PROJECT

HOW TO START
1. Extract the ZIP archive.
2. Open the food-world-final folder in Visual Studio Code.
3. Open index.html directly in a web browser, or use VS Code Live Server.
4. Use Regions in the navigation, the interactive map, or the region cards.
5. On a region page, search for a dish and click “View recipe & details”.

9 HTML PAGES
index.html, asia.html, africa.html, europe.html, north-america.html,
south-america.html, oceania.html, useful-links.html, about-us.html.

FILES
style.css — one external responsive stylesheet.
app.js — menu, dish search, and recipe popups.
data.json — editable region/dish source data.
images/ — 30 local SVG food illustrations (they work OFFLINE).

IMPORTANT
The food pictures are illustrative SVG artwork, NOT actual photographs.
If your teacher requires real photography, replace each illustration with an
appropriately licensed local JPG/WebP and update its HTML image src.
External YouTube, TikTok and recipe resources require internet access.
The 30 dishes are curated selections, not an objective fame ranking.
Team names in about-us.html are transcribed from the submitted sketch;
verify spellings before submission.
